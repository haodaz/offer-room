agents: - name: offer-scout # official pages - name: offer-mentor # advisors' papers - name: offer-critic # her record, cold - name: offer-writer # her story - name: offer-funder # money - name: offer-interviewer # practice rooms: - name: offer-room # the team - name: interview-room - name: mentor-room - name: funding-desk - name: writing-desk bridge: "{bridge}" # Discord here

Each agent is a Claude Code session with its own harness and notebook in the repo.

Switch Console imports the file, creates the agents on this laptop, and opens the rooms in Discord.

The same file runs on Slack, Teams, Telegram or Mattermost.
